## Как я работаю

**Бизнес-задача → процесс → продукт → проверка → внедрение.**

- Начинаю с решения, которое нужно принять, и работы, которую нужно упростить.
- Связываю задачи, ответственность и показатели с реальным процессом.
- Сохраняю источник данных и возможность проверить результат.
- Разделяю работающие функции, пилоты и планы развития.

**Инструменты в проектах:** TypeScript / JavaScript, React, Python, Cloudflare Workers / D1 / R2, Google Sheets, Bitrix24, Telegram, AI и Codex.
